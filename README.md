# SAW STORE Proxy Server

خادم وسيط لجلب بيانات سلة شي إن وتحويل الأسعار إلى الدينار العراقي مع خصومات الكويت.

## خطوات التشغيل
1. انسخ هذا المستودع إلى حسابك في GitHub.
2. اربطه مع Render أو Vercel.
3. بعد النشر، انسخ الرابط العام مثل:
   https://saw-store.onrender.com
4. ضع الرابط في ملف index.html داخل Bolt.
